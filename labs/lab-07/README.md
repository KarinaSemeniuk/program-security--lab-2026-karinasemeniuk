## Фактичні результати збереженого запуску

- Початковий рядок: `2026_КБЗІ-23-2_Семенюк_Каріна_варіант:08`.
- Змінений рядок має `варіант:09`. Це рівно один змінений символ, байт і біт UTF-8; довжина обох рядків — 40 символів, 64 байти.
- SHA-256: змінилося **128 із 256 бітів**.
- HMAC-SHA-256: справжнє повідомлення прийнято; змінене повідомлення та ключ з одним зміненим бітом відхилено. Між HMAC №1 та №2 змінилося **136 із 256 бітів**.
- AES-256-GCM: справжній шифротекст успішно розшифровано; зміна одного байта зі старою міткою відхилена. Відкритий текст при невдалій перевірці не повертається.

Повні хеші, HMAC, випадкові навчальні ключі, nonce, шифротекст і tag містить `integrity-results.json`. Текст фактичного запуску — `experiment-output.txt`.

## Контроль цілісності в RoomBook

Захищені нотатки використовують AES-GCM та AAD; JWT — HS256 разом із серверною перевіркою сеансу; файли збірки — SHA-256-маніфест, автентифікований RSA-PSS-підписом. Один незахищений файл із контрольними сумами не вважається доказом походження.

`npm run check:release-integrity` успішно перевірив чотири сценарії: справжній підписаний маніфест приймається; зміна файла, підпису та додавання незареєстрованого файла відхиляються. Сценарій використовує тимчасові файли й тестову пару RSA та не змінює справжню збірку або ключі встановлення.

Лавинний ефект тут проілюстрований вимірюванням одного запуску, а не статистичним доказом криптографічної стійкості. HMAC порівнюється через `timingSafeEqual`. Результат `decipher.update()` не видається до успішного `decipher.final()`.
