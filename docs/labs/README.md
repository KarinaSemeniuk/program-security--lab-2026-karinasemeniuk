# Лабораторні роботи з безпеки програмного забезпечення

Варіант 8 · Семенюк К. Д. · КБЗІ-23-2.

Звіти оформлено за наданим університетським зразком. Код, відтворювані сценарії та результати перевірок наведено в каталозі `labs/`.

| Робота | Звіт | Практична частина |
|---|---|---|
| 10–11 | [Word](Лабораторна_10–11_Семенюк_КБЗІ-23-2.docx) | [REST-клієнт і HTTP-перевірки](../../labs/lab-10-11/) |
| 12 | [Word](Лабораторна_12_Семенюк_КБЗІ-23-2.docx) | [Аналіз Libraxis і журналювання RoomBook](../../labs/lab-12/) |
| 13–14 | [Word](Лабораторна_13–14_Семенюк_КБЗІ-23-2.docx) | [E2EE і ланцюг SHA-256](../../labs/lab-13-14/) |
| 15–16 | [Word](Лабораторна_15–16_Семенюк_КБЗІ-23-2.docx) | [Резервування, відновлення та реліз](../../labs/lab-15-16/) |

Журнали Libraxis є наданими навчальними матеріалами. `python3 labs/lab-12/analyze_logs.py` відтворює їх кількісний аналіз; SQL-фрагменти обробляються як текст і не виконуються.

Перевірки проєкту: `npm test`, `npm run typecheck`, `npm run test:types`, `npm run typecheck:frontend`, `npm run build`, `npm run build:frontend`. Тести навчального REST-клієнта: `node --test labs/lab-10-11/library-client.test.mjs`.
